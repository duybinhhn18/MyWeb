Ghi chép học javascript

I.Hàm alert, console.log: Hiện text ra trang web

1.Hàm alert

-Chức năng: Hiển thị một hộp thoại chứa văn bản trên trang web.

-Cú pháp:

alert("Helo")

2.Hàm console.log

-Chức năng: hiển thị văn bản ngay trong console của web.

-Cú pháp:

console.log("Helo")

II.Hàm promt: nhập dữ liệu

-Chức năng: hiển thị một ô nhập liệu cho người dùng ở đầu trang web.

-Cú pháp:

prompt("Hay nhap ten cua ban: ")

III.Biến và khai báo biến

1.Biến và khai báo biến

-Khái niệm: biến là một ô nho81 trong bộ nhớ được đặt tên và sử dụng để lưu trữ giá trị.

-Các từ khóa khai báo biến:

Keyword Mô tả
var Từ khóa khai báo biến trước ES6
let Từ khóa khai báo biến được giới thiệu từ ES6
const Khai báo hằng số: biến không thể thay đổi giá trị sau khi đã được gán

-Cú pháp:


// Khai báo biến (không gán giá trị)
var My_name;
let Your_name;

// Khởi tạo biến (có gán giá trị)
var Tuoi = 16;
const doSoi = 100;
let first_name = "Gay";

// Xuất giá trị của biến
console.log(doSoi)
console.log("Nhiệt độ sôi của nước là: " + doSoi + " độ C")
console.log("Tuổi của " + first_name + " là: " + Tuoi + " tuổi")

2.Quy tắc đặt tên biến

-Tên biến có thể bắt đầu bằng chữ cái, dấu gạch dưới _ hoặc dấu $.

-JavaScript phân biệt chữ hoa và chữ thường, nên age và Age là 2 biến khác nhau.

-Không trùng với các từ khóa của JavaScript: tránh sử dụng các từ khóa có sẵn trong JavaScript như var, let, const, if, else, for, while,... làm tên biến.

-Tuân theo quy ước đặt tên biến theo kiểu camelCase: chữ cái dầu tiên của từ thứ 2 viết hoa, còn lại viết thường. Ví dụ: "yourName"

IV.Các kiểu dữ liệu trong JS

STT Kiểu dữ liệu Mô tả Ví dụ
1 String Kiểu chuỗi: kiểu dữ liệu đẻ lưu trữ chuỗi kí tự. let myString = "Xin chao"
2 Number Kiểu số: Kiểu dữ liệu để lưu trữ số, có thể là số nguyên hoặc số thực. let soNguyen = 10;
let soThuc = 3.14;
3 Boolean Kiểu logic chỉ có thể nhận giá trị true hoặc false let isTrue = true;
let isFalse = false;
4 Underfined Biến chưa được gán giá trị sẽ có kiểu dữ liệu là undefined
5 Null Biến chưa được gán giá trị là null.
Thường được dùng để reset biến, gán giá trị mặc định. 		let nullValue = null;

V.Các cách xuất dữ liệu trong JS

-Code:


// Các cách xuất dữ liệu
let soA = 25
let soB = 5

// Cách 1:
console.log("Căn bậc 2 của " + soA + " là: " + soB)

// Cách 2:
console.log("Căn bậc 2 của" , soA , "là:" , soB)

// Cách 3:
console.log(`Căn bậc 2 của ${soA} là: ${soB}`)

// Cách 4
console.log(`Căn bậc 2 của %s là: %s `, soA, soB)

// Luyện tập
let a = 4,
    b = 3,
    kq = a * b;

console.log(`${a} x ${b} = ${kq}`)

VI.Các phép toán cơ bản trong JS

-Code:


// Các phép toán trong JS
let A = 3;
let B = 2;

// Các phép toán
let tong = A + B;
let hieu = A - B;
let tich = A * B;
let thuong = A / B;
let soDu = A % B;

// Xuất kết quả
console.log(`Tổng 2 số ${A} và ${B}: ${tong}`)
console.log(`Hiệu 2 số ${A} và ${B}: ${hieu}`)
console.log(`Tích 2 số ${A} và ${B}: ${tich}`)
console.log(`Thương 2 số ${A} và ${B}: ${thuong}`)
console.log(`Số dư phép chia 2 số ${A} và ${B}: ${soDu}`)

VII.Ép kiểu dữ liệu

-Các hàm ép kiểu dữ liệu:

STT Hàm Ý nghĩa
1 parseInt Chuyển sang kiểu dữ liệu số nguyên.
2 parseFloat Chuyển sang kiểu dữ liệu số thực.
3 Number Chuyển sang kiểu dữ liệu số (bao gồm int và float).

-Code:


// Ép kiểu dữ liệu
// Nhập dữ liệu + chuyển sang kiểu Int
let NumberA = parseInt(prompt("Hãy nhập vào số A: "))

// Nhập dữ liệu + chuyển sang kiểu Float
let NumberB = parseFloat(prompt("Hãy nhập vào số B: "))

// Nhập dữ liệu + chuyển sang kiểu Number
let NumberC = Number(prompt("Hãy nhập vào số C: "))

VIII.Toán tử gán

-Các toán tử gán:

Phép tính Giải thích Công thức Ý nghĩa
= Gán bằng x = 1 x = 1
+= Gán cộng x += y x = x + y
-= Gán trừ x -= y x = x - y
*= Gán nhân x *= y x = x * y
/= Gán chia x /= y x = x / y
%= Gán chia lấy dư x %= y x = x % y

IX.Toán tử tiền tố, hậu tố (prefix, postfix)

1.Trong biểu thức đơn giản

-Các toán tử tiền tố, hậu tố:

Ký hiệu Giải thích Cách biểu đạt Kết quả
++ Tăng giá trị lên 1 a = 1, a++ a = 2
-- Giảm giá trị đi 1 a = 1, a-- a = 0
Phép tính đơn lẻ , viết ++, -- trước hay sau đều được.

-Code:


// Toán tử tiền tố hậu tố
let a = 2;
let b = 3;
let c = 4;
let d = 5;

a++ // Tăng a lên 1 đơn vị: a = 3 
b-- // Giảm b đi 1 đơn vị: b = 2 
++c // Tăng c lên 1 đơn vị: c = 5 
--b // Giảm d đi 1 đơn vị: d = 4

2.Trong biểu thức phức tạp

-Thứ tự thực hiện phép tính như sau:

Step 1: Tính Prefix

Step 2: Tính các phép toán còn lại

Step 3: Gán giá trị cho biến ở bên trái dấu bằng

Step 4: Tính Postfix

-Ví dụ:


// Thứ tự thực hiện phép toán
let a = 1;
let b = 2;

let kq = a++ - ++b + 1;

// Thứ tự như sau:
// ++b => b = 3
// a = 1, b = 3 => 1 - 3 + 1 = -1
// kq = -1
// a++ => a = 2
